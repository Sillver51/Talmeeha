Project guide for Claude Code. Keep this file tight; deep detail lives in linked docs.

## What this is

**تلميحة (Talmeeha)** — a real-time, Arabic, team word-deduction game (Codenames-style).
Two teams (red/blue); each team's **leader (القائد)** gives a one-word **hint (تلميحة)** + a
number; teammates guess words on a 5×5 board. Hit your color = keep going; hit neutral/enemy
= turn ends; hit the **assassin (القاتل)** = instant loss. First team to clear its words wins.

Two modes: **host** (one device, pass-and-play) and **online** (4-digit room codes, many devices).

## Status

Migrating from vanilla (Express + Socket.io + one big `index.html`) to **Next.js 16 (App
Router) + React 19 + TypeScript**, custom server + Socket.io, deployed to **Railway/Render**.
Requires Node ≥ 20.9 (Turbopack is Next 16's default bundler — no webpack config). The legacy
app is `server.js` + `public/index.html` (reference for parity until the port lands).

## Conventions (project-specific; global rules still apply)

- **Arabic-first, RTL-native.** All UI copy is Arabic. App is `dir="rtl" lang="ar"`. Use
  logical CSS properties; `margin-*-auto` for far-edge push. Mirror directional icons.
- **One font:** Tajawal only. Hierarchy comes from weight (600 body, 800–900 headings/actions).
- **Color = meaning** (never decorative): gold = leadership, grape = brand, purple = doubt,
  red/blue = teams, sand = unrevealed word. Don't recolor word-card state classes.
- **Server is authoritative.** Clients render server `state`; never compute game truth client-side.
- **Pure game logic** lives in `src/lib/game/` — deterministic, immutable, unit-tested. Socket
  handlers stay thin (validate → call pure fn → store → broadcast).
- **Validate every inbound socket payload with Zod** (boundary validation). No `any`.
- **Shared types** in `src/lib/types/` are imported by both server and client — keep the
  socket contract type-safe end to end.
- **Immutability** everywhere (per global coding-style): return new objects, don't mutate.
- Keep files focused (200–400 lines typical). Many small components > one big render loop.
